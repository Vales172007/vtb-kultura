# ВТБ Культура — концепт-MVP

Концепт команды для кейс-чемпионата «Молодежный Банк ВТБ». Не официальный продукт банка.

- `index.html` — приложение на весь экран (для телефона)
- `presentation.html` — версия для показа на компьютере: описание слева, приложение в рамке телефона

Сайт статический, публикуется через GitHub Pages.
